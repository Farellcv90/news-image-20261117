# news-image-20261117

A Node 22 program (`main.ts`, standard library only) that draws a newspaper front page summing up the world's news of Tuesday 17 November 2026 — the Kerch Bridge strike, tankers burning off Hormuz, Trump in Manila, the JPMorgan banking outage, the Vulcan rocket failure, the Pentagon's ninth failed audit, and Europe's Rwanda return-hub plan — and writes it as a deterministic 1024×1024 PNG to `/output/entry.png`. Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
